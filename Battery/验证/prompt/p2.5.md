==================================================
二、State 定义必须只使用当前和历史信息
==================================================

不能使用未来 SOH 来定义当前 state。

state 必须从：

t 时刻及之前的信息

构造。

主 state representation 使用过去 L=32 个 SOH：

SOH_{t-31:t}

提取：

1. current_soh = SOH_t

2. soh_slope：
过去 32 cycle 做线性拟合的 slope

3. mean_degradation_rate：

mean(SOH_{k-1} - SOH_k)

4. recent_degradation_rate：
最近 8 cycle 的平均下降速率

5. volatility：
过去 32 cycle SOH first difference 的标准差

所有 state 特征必须严格 causal。

==================================================
三、不要直接把 SOH 高低当作唯一 state
==================================================

因为 CALCE 四块电池的生命周期轨迹可能不同。

本实验至少实现两种 state definition。

--------------------------------
State Definition A：SOH level
--------------------------------

按当前 SOH_t 在每块电池内部划分：

Early
Middle
Late

建议使用 battery-specific tertile：

top 1/3 -> Early
middle 1/3 -> Middle
bottom 1/3 -> Late

该定义只是 sensitivity analysis。

--------------------------------
State Definition B：Degradation dynamics
--------------------------------

使用：

SOH slope
recent degradation rate

定义：

Slow degradation
Medium degradation
Fast degradation

推荐按每块电池内部 slope / degradation-rate tertile 划分。

如果 slope 为负：

绝对退化速度越大 -> Fast

该定义作为主要 state analysis。

必须确保 state label 只由过去信息决定。

==================================================
十四、最终判断标准
==================================================

最后输出：

VALIDATION_V25_SUMMARY.md

只能给以下三种结论之一。

--------------------------------
Conclusion A：
Strong State + Horizon Support
--------------------------------

满足大部分：

1. Group utility 随 horizon 改变；
2. 同一 horizon 下，不同 state 的 group utility 明显不同；
3. State × Horizon interaction 超过 permutation null；
4. 至少 3/4 battery 方向一致；
5. state-conditioned HF prediction gain 有明显差异；
6. degradation-dynamics state 比单纯 cycle-position 更有解释力。

此时推荐：

w_g = w_g(X, h)

即：

State + Horizon Adaptive Routing

--------------------------------
Conclusion B：
Horizon Stronger Than State
--------------------------------

如果：

horizon dependency 保留，

但不同 state 之间 feature utility 差异较弱，
interaction 不稳定或不显著，

则结论：

State conditioning 暂无充分必要性。

后续优先做：

w_g(h)

或轻量：

w_g(z,h)

但不能把 state-aware 作为核心创新。

--------------------------------
Conclusion C：
State Dominates / Horizon Weak
--------------------------------

如果：

feature utility 主要随 degradation state 改变，

而同一 state 内 horizon effect 很弱，

则不要继续强调 horizon-aware。

研究方向改为：

Degradation-State Adaptive Feature Fusion
